Everything you need

🧠

AI-Powered Scoring

Uses the aesthetic-predictor-v2-5 model (SigLIP-based) to score images on a 1–10 scale. Optimized for Apple Silicon (MPS).

📂

Finder Integration

Writes XMP star ratings and Finder tags directly to your files. Sort by rating in macOS Finder to see your best shots first.

⚡

Built for Speed

Scans 100,000+ images efficiently. Resumable across runs thanks to a robust SQLite cache. Skips already-scored images.

🛡️

Safety First

Persists scores to SQLite before writing metadata. A crash or error never loses a result. Failures are logged for review.

How it works

01

Scan

Scans your photo library for supported formats: .jpg, .png, .heic, and more.

02

Score

Processes images through the SigLIP model on your GPU (MPS) or CPU to get an aesthetic score.

03

Write

Embeds XMP Star Ratings (1–5 ★) and numeric Finder tags into the image metadata using exiftool.

04

Sort

Open Folder → View as List → Sort by Rating. Your best shots are at the top, instantly.

Get Started

1. Clone the repository
git clone https://github.com/wenzelt/image-classifier
cd image-classifier
2. Install uv & exiftool
brew install uv exiftool
3. Sync & Run
uv sync
uv run classify ~/Photos/vacation
